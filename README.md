# Pirate Invasion
A small personal 2D game built with Python.

## How to Play
1. Make sure Python and Pygame are installed
2. Clone or download the repo
3. Run `pirate-invasion.py`

## Controls
| Key | Action |
|-----|--------|
| W | Move up |
| S | Move down |
| Space | Shoot |

*This is a personal project built for fun.*
